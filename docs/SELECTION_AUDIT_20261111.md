# 후보 선별 개정 결과 — 2026-11-11

## 반영 범위

개정 원문과 회사 역할을 연결하는 선별, 개정 버전별 안내서 생성, 지정 양식 보존 및 배포 검증을 반영함. 검토 화면 개발은 범위에서 제외하고 관련 파일은 로컬에 보존함. 종료 시점의 결론은 이 기록과 [후보 선별 기준](CANDIDATE_SELECTION.md)을 정본으로 사용함.

## 확인한 문제와 변경

- 개인 주택세제·개인 신청서류·소방기관 활동까지 회사 관련 조건부 후보에 포함되던 범위를 좁힘. 변경 조문 전체가 확인된 범위에 속하고 회사·고용주·금융기관 업무 변경 근거가 없는 경우만 참고로 분류함.
- 공식 신구조문의 `<삭 제>`를 HTML 태그로 제거하던 오류를 수정함. 구·신조문을 함께 확인하고 빈칸은 삭제의 근거로 처리하지 않음.
- 부정 표현, 다른 기관으로 바뀐 주체, 특정 지원대상 기업 조건을 회사의 일반 의무로 해석하지 않도록 보완함.
- 우선 안내로 선정되지 않은 후보도 원문·사유와 함께 보존함. 원문 충돌·타법개정·미확보는 중요도와 별개로 보류함.

[시행령 해당 버전](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=291367)도 함께 확인함. 양육비 채무자 정보제공에 관한 제17조의 폐지로 확대하지 않음.
