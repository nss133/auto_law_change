## 수정한 실행 계약

- 기간 모드 기본값을 개별 안내서 + 목차 + 요약문으로 바꿈. 요약 전용과 법령군별 병합은 명시 옵션으로 분리함.
- 사용자 지정 참고 DOCX를 templates/guide_reference.docx로 보존하고 고정 해시를 검사함. 패키지뿐 아니라 본문 역할별 서식·필수 제목·섹션 순서를 검사함.
- 파급효과 생성은 enrichment로 통합함. 안내서·요약문 렌더링 중 숨은 API 호출을 제거함. API 응답 ID·모델·토큰·원문/프롬프트/응답/최종 문구 해시가 없는 문구·캐시는 성공으로 처리하지 않음.
- 원문 대조 수정은 set_reviewed_impact로 API 원문·수정 사유·검토자와 결합함. 공보험/민영보험, 국가기관/회사 의무, 적용대상·예외·향후 시행일을 프롬프트와 검수 항목에 반영함.
- 원문 미확보·타법개정·서로 다른 법령에 동일한 개정이유가 제공된 경우를 보류함. 입력 한도 초과 시 잘라서 생성하지 않음.
- 미검수, 오래된 해시에 대한 검수, 일부 페이지만 검수, 원문·대비표 누락, DOCX·첨부 변경 또는 누락이면 배포 ZIP 생성을 차단함. 검수 기록은 실제 수행자가 수행 사실을 기록하며 자동 법률 확정을 의미하지 않음.
- 테스트는 외부 네트워크를 차단함. API 예외 메시지에 전체 URL·키가 출력되지 않게 함. 기존 출력 폴더 덮어쓰기와 기간 일부 입력 시 오늘 날짜로 대신 실행하는 동작도 차단함.
- AGENTS.md, CLAUDE.md, README.md와 docs/DELIVERY_HARNESS.md를 같은 계약으로 연결함.
